## 第1课：环境搭建与项目导读

**目标**：能够编译运行项目，理解项目全貌

**内容**：
- 安装 Qt 6.x（MSVC 工具链）、配置 MSVC 2022
- 配置 FFmpeg 7.x 库（头文件 + .lib + .dll）
- 用 Qt Creator 打开 `untitled5.pro`，理解 `.pro` 文件中的库链接配置
- 阅读 `main.cpp`：程序入口、崩溃捕获初始化、Qt 元类型注册
- 浏览项目所有文件，建立模块地图

**关键文件**：`untitled5.pro`、`main.cpp`

**作业**：成功编译并运行项目，截图记录运行界面

---

## 第2课：C++20 与 Qt6 核心基础

**目标**：掌握项目中用到的 C++ 和 Qt 核心语法

**内容**：
- C++20 特性回顾：`std::atomic`、Lambda、范围 for、结构化绑定
- Qt 信号槽机制：`connect` 的四种写法，跨线程信号槽（`Qt::QueuedConnection`）
- `QThread` 的正确使用方式（Worker 对象 vs 继承 QThread）
- COM 智能指针 `ComPtr<T>`（WRL）与 `winrt::com_ptr<T>` 的区别
- `QMutex` / `QRecursiveMutex` / `std::atomic` 的适用场景

**关键文件**：`Logger.h`、`EventBus.h`（信号槽部分）

**作业**：手写一个线程安全的单例模板类，支持跨线程信号通知

---

## 第3课：项目整体架构与 EventBus

**目标**：理解整个系统的通信机制和解耦设计

**内容**：
- 为什么需要事件总线？直接调用 vs 发布-订阅模式的对比
- 阅读 `EventBus.h`：单例实现、信号分类（cmd_ / data_ / state_）
- 完整调用链追踪：用户点击"开始录制" → EventBus → SystemController → 各模块
- `RecorderConfig.h`：录制参数结构体设计，理解配置数据流向
- 画出完整的模块依赖图

**关键文件**：`EventBus.h`、`RecorderConfig.h`、`mainwindow.cpp`（信号发送部分）

**作业**：在纸上画出"用户点击录制"到"第一帧写入文件"的完整调用链

---

## 第4课：SystemController 与多线程管理

**目标**：理解核心控制器如何协调所有模块

**内容**：
- 阅读 `SystemController.h/cpp`：成员变量、线程管理、生命周期
- 生产者-消费者模式：采集线程（生产帧）→ 编码线程（消费帧）
- 状态机设计：Idle → Recording → Stopping 的状态转换
- 资源管理：模块的启动顺序与停止顺序（为什么顺序很重要）
- 线程安全的帧队列：`QMutex` + `QQueue` 的组合使用

**关键文件**：`SystemController.cpp`、`SystemController.h`

**作业**：为 SystemController 画出状态机图，标注每个状态转换的触发条件

---

## 第5课：DXGI 屏幕采集

**目标**：掌握用 DXGI 捕获桌面画面的完整流程

**内容**：
- Windows 图形架构概览：GDI → DXGI → WGC 的演进
- Direct3D 11 基础：`ID3D11Device`、`ID3D11DeviceContext`、纹理（Texture2D）
- DXGI 桌面复制 API：`IDXGIOutputDuplication::AcquireNextFrame`
- Staging Texture：GPU 纹理 → CPU 内存的数据回读
- 多显示器枚举与切换：`IDXGIAdapter` → `IDXGIOutput`
- 常见问题：安全桌面（UAC 弹窗）导致采集中断的处理

**关键文件**：`DxGiCapturer.h/cpp`

**作业**：修改 DxGiCapturer，使其能够输出当前帧的分辨率和帧率到日志

---

## 第6课：WGC 窗口采集与 D3D 纹理操作

**目标**：掌握现代 Windows 窗口捕获 API

**内容**：
- WGC（Windows Graphics Capture）vs DXGI 的对比：适用场景、权限要求
- WinRT 异步编程模型：`IAsyncOperation`、`co_await`、`winrt::resume_background`
- `GraphicsCaptureItem`：从窗口句柄（HWND）创建捕获项
- `Direct3D11CaptureFramePool`：帧池的创建与帧到达回调
- D3D11 纹理格式转换：`BGRA8` → `NV12`（YUV，FFmpeg 所需格式）
- GPU 合成渲染：将摄像头画面叠加到屏幕画面

**关键文件**：`WgcCapturer.h/cpp`、`DxGiCapturer.cpp`（GPU合成部分）

**作业**：对比 WgcCapturer 和 DxGiCapturer 的帧获取方式，总结各自优缺点

---

## 第7课：WinRT 摄像头采集

**目标**：掌握 WinRT MediaCapture 摄像头接入

**内容**：
- WinRT 编程模型：C++/WinRT 语言投影、`winrt::init_apartment`
- `MediaCapture` 初始化：设备枚举、权限申请、格式协商
- 帧池预热（Frame Pool Warm-up）：为什么需要预热，如何实现
- `MediaFrameReader`：异步帧到达事件处理
- 摄像头帧（NV12/BGRA）→ D3D11 纹理 → 叠加到预览画面
- COM 线程模型（STA/MTA）与 Qt 主线程的协调

**关键文件**：`WinRTCamera.h/cpp`

**作业**：阅读"解决程序运行奔溃问题"版本，找出崩溃原因并理解修复方案

---

## 第8课：WASAPI 音频采集与混音

**目标**：掌握 Windows 音频采集和多路混音

**内容**：
- Windows 音频架构：MMDevice API → WASAPI
- 共享模式 vs 独占模式：项目选择共享模式的原因
- 麦克风采集：`IAudioCaptureClient`、PCM 格式（采样率/位深/声道）
- 系统环回音频（Loopback）：捕获电脑播放的声音
- 多路音频混合：两路 PCM 数据的叠加算法（防止溢出）
- 音频格式转换：`WAVEFORMATEX` → FFmpeg `AVSampleFormat`

**关键文件**：`WasapiCapturer.h/cpp`

**作业**：对比"实现音频设备发现"和"解决混音问题"两个版本，理解混音问题的根因

---

## 第9课：FFmpeg 编码基础

**目标**：掌握 FFmpeg 视频和音频编码流程

**内容**：
- FFmpeg 核心数据结构：`AVFrame`、`AVPacket`、`AVCodecContext`
- H.264 视频编码：编码器初始化、`libx264` 参数（preset/crf/profile）
- AAC 音频编码：`libfdk_aac` vs `aac`，采样率/码率配置
- 编码循环：`avcodec_send_frame` → `avcodec_receive_packet`
- 像素格式转换：`swscale`（BGRA → YUV420P）
- 音频重采样：`swresample`（float32 → s16，采样率转换）

**关键文件**：`FFmpegRecorder.cpp`（编码器初始化部分）

**作业**：单独写一个程序，用 FFmpeg 将一张 BMP 图片编码为 H.264 视频帧

---

## 第10课：FFmpeg 混流与音视频同步

**目标**：理解音视频同步原理，掌握 MP4 封装

**内容**：
- 时间戳体系：PTS（显示时间戳）、DTS（解码时间戳）、time_base
- 音视频同步策略：以音频时钟为基准，视频帧对齐
- `AVFormatContext`：MP4 容器封装，`av_interleaved_write_frame`
- 多路流（视频流 + 音频流）的交织写入
- 录制计时精度优化：为什么用帧计数而不是系统时钟
- 正常结束 vs 异常中断：`av_write_trailer` 的重要性

**关键文件**：`FFmpegRecorder.cpp`（混流与写入部分）

**作业**：阅读"优化录制时间精确到秒"版本，理解计时精度问题的根因和修复方案

---

## 第11课：RTMP 直播推流

**目标**：掌握 RTMP 推流的实现方式

**内容**：
- 直播协议概览：RTMP vs HLS vs WebRTC
- FFmpeg RTMP 输出：`avformat_alloc_output_context2("flv", ...)`
- 推流参数配置：服务器地址、推流码、低延迟参数
- 双输出路径：同时录制本地文件 + 推流（两个 `AVFormatContext`）
- 网络异常处理：断线重连策略
- 推流码率控制：CBR（固定码率）vs VBR（可变码率）

**关键文件**：`FFmpegRecorder.cpp`（RTMP部分）、`SettingsDialog.cpp`（直播配置UI）

**作业**：用 OBS 或 nginx-rtmp 搭建本地 RTMP 服务器，测试推流功能

---

## 第12课：Qt 无边框窗口与自定义控件

**目标**：掌握 Qt 自定义窗口外观的实现方式

**内容**：
- 无边框窗口原理：`Qt::FramelessWindowHint` + 自定义标题栏
- 自定义拖拽移动：重写 `mousePressEvent` / `mouseMoveEvent`
- 自定义缩放：8个方向的 resize 区域检测与处理
- 自定义最大化/最小化：处理 `WM_NCHITTEST` Windows 消息
- `SettingsDialog`：模态对话框、参数双向绑定
- `AddSourceDialog`：动态 UI（根据选择显示不同控件）

**关键文件**：`FramelessWidget.h/cpp`、`SettingsDialog.cpp`、`AddSourceDialog.h`

**作业**：为 FramelessWidget 添加窗口阴影效果（使用 `DwmExtendFrameIntoClientArea`）

---

## 第13课：QGraphicsScene 图层系统

**目标**：掌握 Qt 图形场景的图层管理

**内容**：
- `QGraphicsScene` / `QGraphicsView` 架构：场景坐标 vs 视图坐标
- `QGraphicsItem` 自定义：`ResizablePixmapItem` 的实现原理
- 图层拖拽：`ItemIsMovable` flag + 自定义 `mousePressEvent`
- 图层缩放：8个控制点的绘制与拖拽逻辑
- Z-order 管理：`setZValue`、图层上移/下移/置顶/置底
- 文字图层：`ResizableTextItem` 的双击编辑实现
- 实时预览：将采集帧（`QImage`）更新到 `QGraphicsPixmapItem`

**关键文件**：`ResizablePixmapItem.h/cpp`、`ResizableTextItem.h`、`mainwindow.cpp`

**作业**：为图层添加"透明度"控制功能（滑块调节 `setOpacity`）

---

## 第14课：日志、崩溃捕获与调试

**目标**：掌握生产级 Windows 应用的调试与稳定性保障

**内容**：
- 多线程安全日志：`QRecursiveMutex` + 宏定义（`LOG_INFO` / `LOG_ERROR`）
- 日志分级与文件输出：`QFile` + `QTextStream` 的线程安全写入
- Windows 崩溃捕获：`SetUnhandledExceptionFilter` + `MiniDumpWriteDump`
- `.dmp` 文件分析：用 WinDbg 或 Visual Studio 打开 MiniDump
- Qt Creator 调试技巧：条件断点、内存视图、线程切换
- 常见崩溃类型分析：空指针、COM 线程违规、D3D 设备丢失

**关键文件**：`Logger.h`、`CrashHandler.h`、`main.cpp`

**作业**：故意在代码中制造一个空指针崩溃，用 MiniDump 定位到崩溃行

## 第15课：版本演进对比与功能扩展

**目标**：通过对比历史版本理解架构演进，完成综合实战

**内容**：

版本演进回顾：

| 版本目录 | 核心变化 | 学习重点 |
|----------|----------|----------|
| `实现录屏/` | FFmpeg 基础录制 | 最简可用实现 |
| `实现音频设备发现/` | 引入 WASAPI | 第一次多线程挑战 |
| `解决混音问题/` | 多路音频合并 | 音频同步技术债 |
| `重构采集逻辑.../` | 显示器切换崩溃修复 | 状态机设计 |
| `优化录制时间精确到秒/` | 计时精度优化 | 时间戳体系 |
| `实现EventBus和无边框风格/` | 架构大重构 | 解耦设计价值 |
| `解决程序运行奔溃问题/` | WinRT 摄像头稳定 | COM 线程模型 |
| `新添直播功能/` | RTMP 推流 | 双输出架构 |
| `新增WGC采集，优化切换逻辑/` | 现代 API 替代 | 技术选型演进 |

**综合实战**：实现"暂停/继续录制"功能
- 需要修改的模块：`EventBus.h`（新增信号）→ `SystemController.cpp`（暂停逻辑）→ `FFmpegRecorder.cpp`（暂停时跳过写帧）→ `mainwindow.cpp`（UI 按钮状态）
- 这个功能横跨四个层，是对整个课程知识的综合检验
